OMG달에 닿기 위한 마지막 3 km
Problem

ispace는 두 번 달에 닿으려 했고, 두 번 다 마지막 순간에 실패했다. 원인은 서로 다르지만 — 하나는 software, 하나는 hardware — 결국 두 실패 모두 "고도를 잘못 알았다"는 한 지점으로 수렴한다.

Two failures
Mission 1 2023.04 · Atlas Crater
Software / Filter 알고리즘 오류
  • crater rim 통과 시 측정 고도와 추정 고도의 큰 불일치 발생
  • software가 정상 sensor 값을 이상값으로 오판 · 차단 (filter)
  • 실제 5 km 상공에서 "착륙 완료"로 인식
  • 호버링 지속 → 연료 소진 → 자유낙하
Mission 2 · RESILIENCE 2025.06.06 · Mare Frigoris
LRF Hardware 이상
  • 유효 거리값 획득이 치명적으로 지연 (예정 3 km → 실제 893 m)
  • 남은 고도 192 m에서 감속 개시, 제동 불가
  • 약 42 m/s로 표면 충돌 (hard landing)
  • guidance는 정상 — 실제 하강 환경에서의 성능 미검증이 급소

M1은 좋은 데이터를 버려서, M2는 데이터를 너무 늦게 얻어서 실패했다. 방향은 반대지만 뿌리는 같다 — 실제 달 강하 조건에서 altitude-sensing chain을 검증하지 못한 것.
